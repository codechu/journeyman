journeyman

Most agent benchmarks score the answer. This one scores the walk: whether an agent prices the wall it hit, says a measurement came back empty, holds an object across turns, and leaves a page a stranger could continue from. Every run is sealed — the scene hashes, the seeds, the model and the judge — so a number can be traced back to what produced it. (These eleven ran without a system text of their own; the seal carries its md5 when one is used.)

Run your own model

pip install journeyman-bench
journeyman run \
  --endpoint https://your-api/v1 \
  --model your-model \
  --judge https://openrouter.ai/api \
  --judge-model other-model

The judge must be a different model than the agent; a run that grades itself is stamped self_judged. A full 24-cell run cost these agents 657K tokens on average — cents for most, and one reasoning model was stopped at 48¢ for 17 cells. A self-hosted judge adds about two hours of local GPU and no money.

Reproducibility: this board was produced by journeyman 0.0.5 and 0.0.7; PyPI ships 0.2.3, and reports written by 0.0.x no longer validate — run journeyman upgrade over them, or read this board as an archive. See versioning.md.
