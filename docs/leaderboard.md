## Reading the board

- **Under the v2.2 questions, almost everyone grinds.** empty-measure is
  now a count — a barren reading followed by another barren reading —
  and 8 of 11 agents score 0.00 on it in every seed; the judge's
  verdicts match the mechanical count on all 32 valid cells. The three
  that ever notice are gpt-oss-120b (0.67), gemini-2.5-flash and
  gpt-oss-20b (0.33). Strength does not buy it.
- **object-hold stopped being a ceiling.** The v2.2 rule scores *when*
  the agent stopped relative to the decisive evidence; agents that kept
  working after finding the fault now read `procedure`. The spread runs
  from 0.00 (kimi, nemotron, gpt-oss-120b) to 1.00 (scout, mistral,
  flash, luna). Doing more after the answer is no longer free.
- **handoff-verification still separates the top**: glm-5.2 is the
  only agent that verified the note in all three seeds; kimi 0.67.
- **relief-page is low for everyone** (best kimi 0.67, glm 0.33); no
  agent reliably leaves a page a stranger could continue from.
- **The order moved.** Rank correlation with the v1.3-judged board is
  0.45: glm-5.2 drops from first to second, gpt-oss-120b from mid-table
  to last — on v2.2 it is the agent most willing to stop measuring, and
  least willing to verify the handoff note. Read rows as profiles; the
  ordering mean is for sorting only.
