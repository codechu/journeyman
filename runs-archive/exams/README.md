# Exam records

Every badge row in `docs/judges.md` is transcribed from a registry JSON
here: per-axis accuracy, each miss with its draws and `case_id`, the
judge model id, the set examined. `council-aggregate.json` is the v2
labelling council's round-by-round outcome per case (labels by family,
flips, seal status). Screening-funnel records (`screen_v2`) sit beside
the full exams. The v1.3 entries are the two badges of the first
labelling, kept for the historical ledger.
